# CAD-V2-05 产物、缓存完整性及保持架 STEP 回读修复

## 已实现

- 从同一组 B-Rep 零件生成多件装配 STEP、单件 STL、参数快照和可哈希校验的 manifest。
- 校验 STEP *所有*回读固体的拓扑有效性，而不只是文件存在或零件数量正确。
- 基于归一化请求哈希、产物版本和 CadQuery 版本生成缓存键；签名/尺寸错误拒绝缓存复用；先暂存、检查通过后原子发布。
- 输出零件 ID、实例 ID、平移坐标、角色、完整度标记（`SIMPLIFIED_CAGE` / `CAGE_OMITTED`）。这些状态不是 Agent 方案批准或制造审核。
- **修复 CAD-V2-04 暴露的实际问题**：原简化球形兜孔经 STEP 往返后出现无效拓扑；改用上、下环缘与球间连接桥的概念结构。环缘/桥直径比例是预览级几何启发式，不是 RoBAS 标准制造规则；已增加严格 STEP 有效性回归。

## 测试/限制

本地 CadQuery 2.8.0 / OCP 7.9.3.1：16 项单测/实际 B-Rep/STEP 测试通过。GitHub 固定 CadQuery 2.5.2 CI 需要以远端运行结果核验。生成的 STL 是每个**唯一部件原型**的网格，不含单独逐球的装配变换；前端应根据 manifest.instances 实例化。当前缓存采用本机目录与原子重命名；尚不提供跨进程 single-flight/分布式锁、用户授权或 HTTP API，属于 CAD-V2-06 范围。

**特别说明：完整冲压保持架、铆接、公差、厂商内部规格、FreeCAD 人工验收仍未完成。**
