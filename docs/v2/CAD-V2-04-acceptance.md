# CAD-V2-04 保持架首期：简化环形球兜

### 实现
- 在深沟球请求中**可选地、显式地**提供 `cage` 对象，支持 `kind: simplified_annular`，需要内径、外径、轴向宽度和球兜间隙，所有长度为毫米。
- 未提供 `cage` 时保留 PR-03 的无保持架语义，不改变已存在请求哈希；提供 cage 时将其完整参数纳入哈希。
- 使用真实 B-Rep 环体减去 `Z` 个球形兜孔，零件数和封闭壳体有效性经过验证；球兜必须保留轴向连接桥以免切断环体。
- 与内外圈及滚动体的实体穿透按体积检查。
- **没有实现 RoBAS 的详细冲压双半笼及铆钉结构**：传入 `detailed_stamping` 必须显式返回 `NOT_SUPPORTED`，不能伪装成完成品。

### 自测与限制
开发环境 CadQuery 2.8.0 / OCP 7.9.3.1：14 项 unit+kernel 测试通过（包括 3 种几何尺寸比例和 14 件零件 STEP 回读）。远端 CI 的 CadQuery 2.5.2 仍须实际执行后验收。所用模型为概念/结构复核级，不代表已完成保持架制造参数、公差、铆钉、双半笼和动态性能校核。
