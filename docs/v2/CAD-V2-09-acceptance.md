# CAD-V2-09 角接触球轴承 B-Rep 建模与验收

目标：在统一 CAD 核心上实现角接触球轴承功能级三维实体，不修改旧滑动轴承工作台。基线 main 29a89408067e801d9c2e314877d8a4d237f5fc18，PR-17 已合并。

## 已实现范围
- 输入显式 mm 尺寸、球径/节圆/数量、内外圈沟曲率、左右不同挡肩直径、contact_angle_deg。
- 在唯一几何公式边界调用 radians；依据球中心与沟圆截面中心的法向几何关系计算两侧偏移环面切削槽。接触角决定轴向偏移与沟中心径向偏移。
- 左右非对称内外圈径向截面旋转生成环体，用环面布尔产生有效沟道。滚动体按节圆等角装配。
- 仅支持固定正向接触角符号（沿 +Z 的名义外圈接触方向），不承诺任意镜像或成对安装。
- 实体 BRepCheck、包围盒、钢球-圈实体穿透和内外圈干涉检查，缓存/manifest/STEP/STL/API 复用原架构。
- 接触角和类型加入 manifest，保持架状态明确 CAGE_OMITTED。

## RoBAS 溯源和限制
RoBAS ACBGeometry 的三角函数调用存在角度/弧度路径歧义，未直接复制经验比例公式。此 PR 是经数学关系约束的独立 Python/OCCT 功能级重建；不意味着再现全部 RoBAS 壳体细节，尚无真实厂商几何、预载、游隙、承载能力与制造公差校核。
保持架、倒角、滚道修形、真实接触力学、成对配置和网页角接触参数选择仍待开发。

## 验收门禁
15°、25°、40° 有效参数下实体闭合/拓扑有效、13 件 STEP 导出并回读有效；非法曲率/肩部/数量/角度须被拒绝；HTTP API 能正常生成 STEP；旧所有 CAD/浏览器工作流不得回归。
GitHub Actions 固定 CadQuery 2.5.2 环境成功后才可声称远端验收。提交新的 feature/cad-v2-09-angular-contact 分支 PR，不自动合并。
