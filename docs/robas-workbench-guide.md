# Bearing_CAD 的 RoBAS 滚动轴承工作台

Bearing_CAD 把 RoBAS 的轴承设计、候选优化、二维出图和拟静力学分析接入同一个网页工作台。你可以先确定轴承长什么样，再用同一套设计尺寸生成模型和图纸，或者换一组载荷与转速查看计算结果。

RoBAS 原版是 C# Windows 桌面软件。Bearing_CAD 迁移了部分设计、优化和输入输出逻辑，用自己的 CAD 建模代码生成三维模型，二维继续使用原版模板，拟静力学的核心数值计算继续由原版 `RoBAS_v2.exe` 执行。

## 现在能做什么

| 功能 | 你要提供什么 | 得到什么 |
|---|---|---|
| **手动设计和初始尺寸** | 选择轴承类型，填写内径、外径、宽度和详细结构参数。深沟球可用原版规则预填初始尺寸，也可手动录入已核实的球数和沟曲率。 | 一套可以编辑、确认并用于后续操作的设计参数。 |
| **优化候选** | 填写尺寸约束和轴承型号。按轴承类型补充游隙组、预载荷或目标权重。 | 按原版规则搜索出的几何候选及评分。卡片展示钢球或滚子尺寸、数量、节圆和相应指标，确认后才应用到设计。 |
| **三维 CAD** | 提交当前设计参数，包括需要建模的滚道、滚动体和保持架。 | 用 CadQuery／OCCT 生成的三维实体及装配。网页可旋转、剖切、爆炸展示，支持导出 STEP 和 STL。改尺寸后重新生成，模型几何随之改变。 |
| **二维工程图** | 提交当前设计、型号及对应的出图选项，例如精度等级和游隙组。 | 使用原版 DWG 模板和 CADImport 生成的 DXF，以及网页 SVG 预览。可查看总装图、内外圈图和模板所支持的零件图。 |
| **拟静力学分析** | 使用成功三维作业的设计快照，选择已核实的 RoBAS 参考配置，填写分析专用尺寸和需要覆盖的工况。 | 本次运行的 `DATA.txt`、原版求解器的 `OUT.txt`、运行记录和网页结果。可查看接触载荷、应力、变形、接触角、旋滚比、油膜、温度、滚动体运动、扫速位移与刚度、总功率损失、内部游隙及原版寿命模型输出。 |

**优化和拟静力学是两次不同的操作。** 优化给你几套可以选择的尺寸方案。拟静力学固定某一套设计，计算它在指定载荷和转速下的表现。优化卡片里的经验刚度用于给候选评分，分析页上的扫速刚度来自原版求解器输出。

## 三类轴承的支持范围

| 轴承 | 优化 | 拟静力学分析 |
|---|---|---|
| **DGB 深沟球** | 按额定动载荷 Cr 和经验径向刚度比较候选。 | 需要填入已核实的分析内圈外径。显式 CAD 保持架暂未映射到分析保持架。 |
| **ACB 角接触球** | 优化区的型号与二维图纸双向同步。支持 70、72、73 系列和 15°、25°、40° 接触角。输入预载荷，旋滚比、Ka、Cr 三项权重合计为 1。原版旋滚比评分方向仍待工程审核。 | 需要明确分析内圈外径，并从当前设计的肩径中选择内、外圈分析挡边。显式 CAD 保持架及显式 CAD 保持架材料目前受限。 |
| **CRB 圆柱滚子** | 按额定动载荷 Cr 比较候选，优化用的径向刚度 Kr 标为不可用。 | 限 N 型直滚子。非零 CAD 径向几何净距时，需要独立填写分析游隙。可生成三维的其他构型和修形组合，分析范围以本项为准。 |

## 从设计到查看结果

1. 进入 `rolling.html`，选择轴承类型并输入参数。手动方案点击「确认当前设计」，优化方案点击对应卡片的「确认并应用此设计」。
2. 生成三维模型。需要图纸时，切换到「二维图纸」生成并查看。同一设计的二维和三维可以核对快照 SHA-256。图纸的型号、精度和模板选项各自生效。
3. 打开「拟静力学分析」，选择可用的参考配置，核对分析几何。可填写 X/Y/Z 载荷、内外圈转速及分析游隙。工况留空时沿用参考 DATA。参考配置由本机服务登记，网页可查看其来源。
4. 点击「运行拟静力学分析」。页面显示本次有效工况、来源、接触分布曲线和运行编号。完整的输入、输出和运行证据保存在本机。
5. 修改载荷或转速后，可以对同一套设计再次运行，旧结果会标为历史。修改设计尺寸后，要重新确认设计并生成对应的三维作业。

### 一个已实测的例子

同一个 DGB 设计先按参考配置运行，Z 向载荷为 **2000 N**，首个滚动体的外圈接触载荷为 **2251 N**。把 Z 向载荷改为 **2400 N** 后重跑，设计哈希相同，运行编号和输出哈希更新，首个滚动体的外圈接触载荷为 **2330 N**。这两组值对应实测案例中的特定几何和工况。

## 怎样理解结果状态

- **设计哈希**用于核对参数版本。用户确认和成功生成 CAD 分别记录。
- **来源哈希已验证**表示输入 DATA 和输出 OUT 与同次求解报告对应。
- **支持的结果段已解析**表示已适配的表格可以读取。单项指标仍有各自的有效性状态，`NaN` 和 `Infinity` 显示为不可用。
- **收敛未知**表示缺少独立的收敛证据。进程退出码 0 只记录执行状态。

## 当前集成范围

工作台包含 [PR #96](https://github.com/GB412/Bearing_CAD/pull/96) 的网页闭环与 [PR #97](https://github.com/GB412/Bearing_CAD/pull/97) 的界面、结果展示和保持架修订。材料、保持架润滑及载荷步数设置也已纳入版本管理；留空时继承所选参考 DATA，可在结果中查看实际生效值及来源。

深沟球工作台已移除简化环缘预览保持架，可选双半笼、球兜和铆钉结构，默认不添加显式保持架。球轴承优化前需取消显式保持架；这不表示实际轴承无需保持架。拟静力学仍使用参考 DATA 中的分析保持架，显式 CAD 保持架组合暂不支持。

## 当前边界

拟静力学依赖 Windows 原版求解器和已核实的参考 DATA。安装配合、运行温度、力矩、滚道油品模型等设置主要来自参考配置。油膜厚度、接触尺寸、温升和承载能力等已按原版输出映射展示；原版寿命模型的适用性及异常原因仍待工程核实，有限数值不代表校核通过。原版的批量设计图册也在当前单轴承工作台范围之外。

后续接入多 Agent 系统时，可复用现有优化、CAD 和分析接口。Agent 可以收集参数、解释候选和结果，用户确认设计及工况后，由工作台的现有计算链执行。
