# 滚动轴承 CAD · 参数编辑与边界检查（PR32）

## 目标与边界
修复“仅将角接触球内径从 40 mm 改为 50 mm，后端英文不等式报错”以及审阅发现的相关问题。

- **独立编辑**：每一个几何尺寸仍是明确用户输入。修改内径**不自动悄悄重算**挡肩、节圆或沟道。页面即时标记明显冲突、相邻关联字段，并以中文解释；后端继续作为真实 B-Rep 校验的唯一最终权威。
- **整体等比例缩放**：在当前一组有效参数的基础上填“目标内径”，将内外径、轴向宽度、球/滚子直径、节圆、沟曲率、肩部、保持架宽径与间隙等**长度尺寸**按相同比例缩放；滚动体数量、接触角、圆柱 N/NU/NJ/NF/NUP 构型保持不变。此操作不是轴承选型，不重新计算承载力/寿命，不保证设计合理性。
- 后端深沟球 `simplified_annular` 补上**保持架宽度 ≤ 轴承宽度**的明确检查。
- 在前端输入、后端 `parse_request`、HTTP API 使用相同的本地 CAD 资源限制：单次最多 64 个滚动体、单项尺寸不超过 1000 mm。零间隙仅开放给圆柱滚子 `radial_clearance_mm` / `axial_clearance_mm` 两项几何净距；其他尺寸仍必须大于零。资源上限不是 ISO/GB 设计标准。
- 将常见后端英文尺寸错误翻译为中文、保留结构化 `field_path` 和原报错的错误代码，前端标记对应字段；未知后端错误仍显示原文字以便诊断。
- 参数修改后旧模型与旧下载继续清空，防止用户把旧模型误认为新参数生成的成果。

## 正确体验示例
角接触球默认内径 40，右肩 47、左肩 49。**只把内径改为 50** 应出现“内径、内圈右肩、内圈左肩……依次增大”的即时警告，点击生成不提交无效 CAD 请求。

要生成同构型更大的几何示意，点击“恢复默认”并在“目标内径”填写 `50` → “整体等比例缩放”。得到外径 85、节圆 67.5、内右肩 58.75、内左肩 61.25、球径 10，接触角仍 25°，球数仍 11；通过实际后端再生成 STEP。

## 验收
1. Node：三类默认请求、两种改参方式、深沟球两种保持架/圆柱窗孔笼/角接触径向笼的同比例缩放、非法边界/零间隙、中英文错误解析。
2. 浏览器 Playwright：非法 40→50 关联字段提示、不发起错误的 CAD 任务；复位后整体缩放验证多个关联输入及原角度/滚动体数。
3. Python/OCCT：三种轴承带保持架放大至内径 50 mm，**真实 B-Rep→STEP 回读**；旧默认几何不变，简化保持架超轴承宽度明确拒绝，资源限制及零间隙路径校验。
4. 真实浏览器/服务：实际等比例调整角接触球至 50 mm 后，生成 13 实例 STEP 并下载检查 `design_snapshot.json`；既有真实无效参数错误清理仍通过。
5. CI CAD-V2、CAD-01、CAD-02/03、Workbench 全部通过方合并。FreeCAD 人工软件验收、RoBAS/Eyeshot 等价和多 Agent 集成依然不在本 PR 范围。

**所有改动不会自动改变已有的用户请求或旧成果参数哈希。**

## 新发现的 STEP 交换精度差异
新增 d=50/D=85 角接触球径向窗孔保持架案例实际触发了原有 STEP 校验：CadQuery/OCCT 2.5.2 报告导出前后体积差 `0.000924175`（约 0.0924%），大于通用 `5e-4` 上限。基准大小约 0.0168%。另在独立 CadQuery 2.8 下复现了尺寸比例敏感的同类误差。尝试单次整体布尔差集和 STEP 写入参数未消除偏差。保留通用零件 `5e-4` 严格门禁，仅对角接触径向窗孔保持架单件使用可追溯的 `1.2e-3`（0.12%）交换门槛。全装配 STEP 数量、有效性、包围盒和质心偏差检查维持原标准；`geometry_quality.json` 会记录专用阈值和实际误差，并给出精度提示。

这只是功能级 CAD 文件格式互操作验证，不是放宽制造公差，也不能证明与 RoBAS 原版 Eyeshot STEP 完全等价。存在超出新阈值的合法几何组合时仍会拒绝发布并要求进一步调查。

进一步测得上述放大比例下，角接触窗孔保持架在导出前后的质心偏差约 `0.00296148 mm`（STEP 实体有效、装配外形边界仍满足原检查）。因此**仅此窗孔笼**额外使用 `0.005 mm` 的质心交换门槛；其余全部零件维持 `0.001 mm`，绝不视为制造尺寸允许误差。两类专用门槛、实际偏差及精度警告都保留在 `geometry_quality.json`。
