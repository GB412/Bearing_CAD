# 保持架界面移除与结构审查（2026-11-16）

## 工作台调整

深沟球的“简化环缘保持架（预览级）”从可选项移除，默认不包含显式 CAD 保持架。用户勾选后可配置双半笼、球兜与铆钉。初始尺寸预填不会把旧简化笼尺寸写进双半笼，优化以无显式保持架的候选搜索；确认后需重新配置双半笼。收到旧简化笼候选时明确拒绝应用，不静默删掉或替换设计部件。

后端历史请求及已导出文件的兼容读取保留；此次不删除旧资源、不修改求解器输入或计算规则。取消 CAD 保持架仅表示该次模型不建它，不表示真实轴承可以不需要保持架。

## 用户四张截图的判断

| 图 | 结构与源码依据 | 能确认的范围 |
|---|---|---|
| 1 | 预览用简化环缘笼，不是双半笼冲压结构 | 不再提供给工作台新设计。 |
| 2 | `stamping.py` 双半笼/球兜/铆钉，参考原版 `BearingModel/Cage/StampingCage.cs` | 结构类别有依据，有独立两半笼和铆钉实体。参数化 OCCT 构造尚无相同参数的原版 Eyeshot STEP 对照，不称制造定型图；板厚字段有轴向余料约束语义，不能直接视为完整钣金工艺参数。 |
| 3 | `cages.py::cylindrical_window_cage`；原版 `CylinderPocketCage.cs:124–160` 环形毛坯减轴向圆柱窗口 | 滚子轴线与窗口轴线一致，兜孔与滚子共享节圆位置。截图选择 NU 构型；当前拟静力学仅支持已验证 N 型直滚子，不能据 CAD 可生成就认为 NU 可计算。 |
| 4 | `cages.py::straight_pocket_cage`；原版 `StraightPocketCage.cs:322–361` 环形毛坯减径向圆柱兜孔 | 有原版构造依据，保留上下轴向边缘及球间连接梁。不能由外观认定所有 ACB 都应采用此笼；材料选择字段用于球数计算，不是制造材料认证。 |

后三者均属于有来源的参数化工程几何，未完成制造工艺、锁球/装配工艺、导向间隙、强度与高速稳定性等专业验收。图中爆炸距离已调大，零件分离是展示变换；检查配合应先归零，再看剖面、兜孔对齐与干涉。
