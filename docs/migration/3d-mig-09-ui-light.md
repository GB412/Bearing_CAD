# 浅色三维工作台视觉规范

此次仅美化 `rolling.html`、`rolling_workbench.css` 与 `rolling_workbench.js`，**不修改几何契约、OCCT B-Rep、STEP/STL 或成果哈希逻辑**。

- 视觉方向：浅灰应用底色、白色表单面板、细边框；不使用深色渐变、大面积装饰卡片或外部字体。
- Three.js 使用透明画布以显示界面的浅灰工程网格。材质采用适度金属感与宽柔光源，不采用彩虹渲染。
- 所有零件色来自 CSS 根变量，为 Three.js 模型、页面颜色图例和装配树单一来源：外圈冷灰钢、内圈深钢蓝、滚动体暖金属、保持架灰绿、活动挡圈赤陶、铆钉浅铜色。双半笼上下片采用明暗不同的灰绿。
- 零件树人类可读中文名称、原始实例 ID 均保留；隐藏/显示、爆炸、剖切、透明、下载功能不变。
- 响应式保留桌面左右双栏，窄屏改为纵向布局。焦点、错误态、引擎在线状态不只使用颜色表达。
- 浏览器测试只检查主题关键色、响应式无横向滚动、零件材料与颜色标识相符，不对截图像素作脆弱断言。

设计尺寸仍是测试夹具，界面变美不代表制造审核通过。
