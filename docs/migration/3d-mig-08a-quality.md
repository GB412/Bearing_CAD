# 3D-MIG-08A · 几何质量收尾

2026-10-27，在 3D-MIG-07A 的七组 OCCT 基线上做最小修复：

1. 增加 **逐实例质心位置集合** 对比，防止只对总体 bbox 和排序体积验收时漏掉内部零件平移错误。导入 STEP 的实体顺序不可信，按质心坐标、体积进行确定性排序；位移大于 0.001 mm 阻断成果发布。
2. 测试中人为移走一个中间方体，同时保持两端整体包围盒与三个相等体积都不变；必须失败。另保留三类轴承已有 STEP 测试和七组迁移基准。
3. 不改变轴承几何构造/导出协议。将 `board_thickness_mm` 网页字段明确标注为**球兜外最小轴向余料约束**，不是精确板厚；兼容旧 API 字段。
4. 生成器版本 `0.9.5` 以隔离先前未进行逐实例质心检查的缓存成果。

此 PR 仅验证几何交换一致性与显示语义，不声称 RoBAS 与 Eyeshot 等价，不承诺制造级公差。详细保持架真实材料厚度依旧需专业审核。
