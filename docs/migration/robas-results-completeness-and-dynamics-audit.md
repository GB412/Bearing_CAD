# RoBAS 结果展示补齐与动力学源码审查

核查日期：2026-11-15。范围为现有 DGB、ACB、CRB N 型拟静力学链路；不增加新的求解模式。

## 结果展示

复用 `robas_results.py` 和工作台结果组件，补齐原版 C# 静态结果读取器中的主要结果类别：

- 接触载荷、应力、变形、接触角，以及套圈挠曲。
- 自转、公转、位置、方向角、离心力和运动坐标系力。
- 旋滚比、滚动速度、滑动速度、牵引系数。
- 接触长短半宽、接触边缘尺寸。
- 油膜厚度、等温油膜厚度、折减系数。
- 油膜温度、接触温度、接触温升、接触功耗。
- 扫速刚度、位移与内外圈转速；配合量、功率损失和内部游隙。
- 承载能力、基本寿命、修正寿命和寿命修正系数的原版模型表。

网页在曲线指标中切换结果，展开分组数据表查看数值。寿命和承载能力仅按原版打印表展示，标明模型适用性未知。空白列保留为“未报告”；NaN / Infinity 为“不可用”，不会转换成零。

未结构化的局部滑动/牵引曲线、套圈/保持架等补充输出，可在“原版完整结果文本”展开查看。`a0_Final` 及辅助文件仍保留哈希，未将未知的向量顺序猜成工程指标。这一轮补齐展示，并不意味着所有原版输出都经过工程认可。

详细字段、单位及 C# 映射见 [结果映射表](robas-solver04-static-result-mapping.md)。未修改 DATA 协议、EXE、参考配置、既有计算公式或原始输出。

## 两处需要明确处理的原版问题

1. N222 输出的油膜温度为 `0 K`。原版直接减去 273.15 会得到看似正常的摄氏温度数值。本版保留原始值并标为不可用，原因未知。原有 5 项 NaN 仍在寿命表，未修改。
2. 原版读取承载能力表时按空格分词，丢失空列，并把两个载荷容量赋给“最大应力/最大负载”属性。DGB 的原始行对应 12420 / 5629 N，不能把第一个数当成 Pa。本版按固定列读取、保留各模型及单位，不复制这个标签错位。

## 动力学调查结论

**目前本机这份 RoBAS C# 源码存在动力学预留代码，但没有查到已启用、可验证运行的完整动力学功能。原版 EXE 的潜在动力学能力仍未确认。**

审查对象为 `D:\RotorStudio\RoBAS`、RotorStudio 下的 `RoBAS` 子项目，以及同目录 `RoBAS.zip`。以下六个文件在三份副本中逐字节一致：

| 源码位置 | 证据 |
|---|---|
| `Utility/Enum.cs:158` | 只有 `拟静力学=-1` 启用；`拟动力学=1` 被注释。 |
| `Core/BaseSolver.cs:16` | 默认选择拟静力学；有时间步、积分方法等配置字段，但字段本身不能证明算法已可用。 |
| `Core/BaseAnalysis.cs:38,79` | 初始化、存放动态结果对象，属于数据容器。 |
| `Core/BallBearing/BallBearingAnalysis.cs:170,294` | 有动态输入生成方法，仍序列化当前 `Solver.Mode`；由外部 EXE 计算。求解后静态和动态分支重复判断同一个拟静力学条件，动态结果分支不可达。 |
| `Core/RollerBearing/CylinderRollerBreaing/CylinderBearingAnalysis.cs:170,315` | 同样存在输入方法和重复判断问题。 |
| `Frm/FrmMain.cs:2157` | 只启用静态结果显示分支，动态显示分支被注释。 |

三个轴承 Server 的动态树节点创建代码均被注释；`MachineElementServer.AddDynamicAnalysisResultNode()` 只是添加结果节点，不是积分求解器。按钮事件调用通用后台分析，未发现有效的独立动态模式切换。注释中“动力学分析耗时”的文字也不是运行证据。

本机源码及压缩包未发现 C/C++/Fortran 数值求解器源文件；主要计算委托给 `RoBAS_v2.exe`。因此无法依据 C# 外壳证明 EXE 不支持动力学，也不能擅自启用 Mode=1。截图中的树节点与这份注释状态不一致，可能来自不同构建，需要对应程序版本或原版动态案例才能进一步确认。

承载能力表中的 `Dynamic Capacities` 位于原版“Fatigue Life Modeling”部分，也不能用这个名称证明执行过瞬态动力学。

后续若要迁移动力学，需要先获得可运行的原版动态案例、对应版本的输入协议、时间历程输出定义和独立数值依据。本次没有试改 Mode，也没有集成 RotorStudio 中其他求解器。
